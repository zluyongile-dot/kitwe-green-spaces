Kitwe Urban Green Space GIS Mapping & Analysis System

Complete Production Build

Project Overview

A highly advanced, full-stack Spatial GIS Mapping application designed specifically to map, monitor, and model urban forestry assets and green equity spaces across Kitwe's 16 municipal wards in Zambia.

The system leverages high-fidelity vector rendering, Live OpenStreetMap geospatial references, and PostGIS database queries to deliver interactive, analytical decision-making services suitable for town planners, climate researchers, and active volunteers.

Comparative Multi-City Methodology

To enhance the analytical rigor of our research, Ndola has been integrated as an active comparative reference and benchmarking city alongside our primary study area, Kitwe.

This allows academic researchers and municipal planners to evaluate urban green space management across different administrative structures, industrial footprints, and population distributions in the Copperbelt Province.

1. Normalized Difference Vegetation Index (NDVI)

The system integrates real-world satellite-derived NDVI values (ranging from -1.0 to 1.0) for every green space to represent canopy vigor and vegetation density. The formula is computed from multispectral bands:

Normalized Difference Vegetation Index Formula
NDVI = (NIR - Red) / (NIR + Red)

Where NIR is Near-Infrared light and Red is visible Red light. In our platform, spaces are categorized dynamically: **Dense Canopy (NDVI > 0.7)**, **Moderate Vegetation (0.5 - 0.7)**, **Sparse Vegetation (0.2 - 0.5)**, and **Water Bodies / Non-vegetated (NDVI < 0.2)**.

2. UN Sustainable Development Goal 11.7 (Indicator 11.7.1)

We measure urban sustainability indicators in compliance with the **UN SDG 11.7** directive: "Provide universal access to safe, inclusive and accessible, green and public spaces, in particular for women and children, older persons and persons with disabilities."

WHO Per-Capita Target

The World Health Organization recommends a minimum target of 9 m² of public green space per capita. The system dynamically computes this metric for Kitwe and Ndola to identify green equity deficits.

10-Minute Walk Buffer

The standard 300m / 500m walksheds (representing a 5 to 10-minute walk buffer) are mapped using Turf.js to analyze spatial accessibility disparities across municipal wards.

Core GIS System Capabilities

Unlike simple mapping overlays, this platform is a fully realized spatial decision-support system featuring live computational components:

Eco-Planner Simulator

Allows users to tap anywhere on the map to mock up a proposed green space, dynamically calculating its cooling circle, 10-minute walk buffer, CO₂ absorption capacity, and ward coverage impacts on-the-fly using Turf.js.

1km Coverage Analysis Grid

Generates a live hexagonal mathematical coverage analysis layer over the entirety of Kitwe, exposing high-priority visual green gaps and proving green equity discrepancies across socio-economic bounds.

3D Satellite Fly-Through Tour

Renders cinematic high-resolution satellite tours around Kitwe's 26 real green spaces, featuring an automated media controller, speed adjustments, and ecological info HUD panels.

Volunteering Events Portal

Integrates a real-time community action center connected directly to backend PostGIS databases, allowing citizens to register, RSVP, and view upcoming environmental cleanups.

Live Environmental Monitors

Fetches live PM2.5, PM10 air quality metrics from WAQI APIs, and hourly temperatures from Open-Meteo weather API to graph microclimate data in real-time.

Interactive Route Planning

Utilizes the Leaflet Routing Machine to compute the fastest route from a user's current geo-location to any green space or water body with active turn-by-turn navigation.

Database Architecture & PostGIS Schema

The backend database uses a fully normalized spatial architecture in **PostgreSQL** with the **PostGIS extension**, keeping live synchronization with front-end fallback files for 100% offline parity:

1. Green Spaces Table Schema

green_spaces.sql 
CREATE TABLE green_spaces (
    id SERIAL PRIMARY KEY,
    name VARCHAR(255) NOT NULL,
    type VARCHAR(100) NOT NULL, -- municipal_park, neighborhood_park, lake, forest
    area_sq_m FLOAT NOT NULL,
    ward VARCHAR(100) NOT NULL,
    image_url TEXT, -- Curated Unsplash category-specific previews
    facilities JSONB, -- JSON arrays mapping facilities like pathways, fields
    accessibility JSONB, -- Wheelchair status, walkable, public transport link
    geom GEOMETRY(Point, 4326) -- PostGIS Point Geometry in WGS84
);

2. Community Volunteering Events Table

community_events.sql 
CREATE TABLE events (
    id SERIAL PRIMARY KEY,
    title VARCHAR(255) NOT NULL,
    description TEXT NOT NULL,
    date DATE NOT NULL,
    time TIME NOT NULL,
    green_space_id INTEGER REFERENCES green_spaces(id) ON DELETE CASCADE,
    max_volunteers INTEGER DEFAULT 50,
    organizer VARCHAR(100) NOT NULL
);

CREATE TABLE rsvps (
    id SERIAL PRIMARY KEY,
    event_id INTEGER REFERENCES events(id) ON DELETE CASCADE,
    name VARCHAR(100) NOT NULL,
    email VARCHAR(100) NOT NULL,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

Environmental Impact Formulas

The system uses specific, empirically grounded environmental factor constants derived from local woodland and turf studies to estimate ecological impacts in the popups and Town-Planner Simulator HUD:

1. Annual Carbon Sequestration ($CO_2$)
CO2_Seq = Area_sq_m * TypeFactor

TypeFactors: **Forest (Miombo)**: 0.85 kg/m²/yr · **Municipal/Local Park**: 0.50 kg/m²/yr · **Garden**: 0.35 kg/m²/yr. Deployed proposed spaces with a tree canopy density upgrade gain an additional 25% sequestration bonus.

2. Stormwater Retention Volume ($V$)
Water_Ret = Area_sq_m * SoilAbs_Factor

SoilAbs_Factor: **Forest / Grassland**: 0.15 L/m² · **Sandy/Loamy Park**: 0.08 L/m². Deployed spaces with structural water retention ponds gain a 35% retention bonus.

3. Microclimate Cooling Radius ($R_c$)
Cooling_Rad = sqrt(Area_sq_m) * TypeConstant

TypeConstant: **Forest**: 9.5 · **Park**: 7.8 · **Garden**: 6.5. This calculates the physical buffer circle showing active urban heat island cooling mitigation on the map canvas.
