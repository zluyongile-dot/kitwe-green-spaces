# Spatial Analysis - Quick Reference Card

## 🎯 5 Features at a Glance

| Feature | Icon | What It Does | When to Use |
|---------|------|--------------|-------------|
| **Heat Map** | 🔥 | Shows density using colors | Find high/low density areas |
| **Buffer Zones** | ⭕ | Shows 500m, 1km, 2km circles | Check accessibility |
| **Clustering** | 🔗 | Groups nearby markers | Reduce map clutter |
| **Coverage** | 📊 | Green (good) / Red (bad) areas | Find underserved areas |
| **Distance** | 📏 | Click to find nearest space | Measure distances |

---

## 🎨 Color Guide

### Heat Map
- 🔵 **Blue** = Low density (few spaces)
- 🟢 **Cyan** = Medium-low density
- 🟡 **Yellow** = Medium-high density
- 🔴 **Red** = High density (many spaces)

### Buffer Zones
- 🟢 **Green** = 500m (~6 min walk)
- 🟡 **Yellow** = 1km (~12 min walk)
- 🔴 **Red** = 2km (~25 min walk)

### Clustering
- 🟢 **Green** = Small cluster (2-10 spaces)
- 🟠 **Orange** = Medium cluster (11-20 spaces)
- 🔴 **Red** = Large cluster (20+ spaces)

### Coverage
- 🟢 **Green** = Well-served (<1km to park)
- 🔴 **Red** = Underserved (>1km to park)

### Distance
- 🟠 **Orange** = Your click point
- 🟠 **Dashed line** = Distance to nearest space

## 🚀 Quick Actions

### Activate Analysis
1. Click analysis button
2. Button turns green with [ON]
3. Analysis appears on map
4. Notification confirms

### Deactivate Analysis
1. Click same button again
2. Button returns to gray with [OFF]
3. Analysis removed from map
4. Notification confirms

### Clear Everything
1. Click "Clear All Analysis" button
2. All analyses removed
3. All buttons reset to [OFF]
4. Notification confirms

## 💡 Best Combinations

| Goal | Use These |
|------|-----------|
| **Find underserved areas** | Coverage + Distance |
| **See overall patterns** | Heat Map + Clustering |
| **Check accessibility** | Buffer Zones + Coverage |
| **Plan new parks** | Coverage + Heat Map |
| **Reduce clutter** | Clustering alone |

---

## ⚡ Performance Tips

| Feature | Speed | Tip |
|---------|-------|-----|
| Heat Map | ⚡ Fast | Zoom out for best view |
| Buffer Zones | ⏱️ Medium | Zoom in to reduce clutter |
| Clustering | ⚡ Fast | Great for many markers |
| Coverage | 🐌 Slower | Be patient (5-10 sec) |
| Distance | ⚡ Fast | Click anywhere on map |

---

## 🐛 Quick Troubleshooting

| Problem | Solution |
|---------|----------|
| Heat map not showing | Zoom out, check data loaded |
| Buffer zones cluttered | Zoom in or use clustering |
| Coverage analysis slow | Normal - wait 5-10 seconds |
| Distance not working | Ensure button shows [ON] |
| Nothing happens | Check browser console |
